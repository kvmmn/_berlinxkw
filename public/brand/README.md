# Brand mark assets

The live site uses **`/public/logo.png`** for the Berlin bear in the neon lime orb (see `BrandLogoMark` in `src/components/BrandLogoMark.tsx`).

Optional vector fallback: add `logo-mark.svg` here and render with `<BrandLogoMark variant="svg" />`.

Neon hex and animation speed are controlled in `src/app/globals.css` (`--bk-lime`, `--bk-logo-morph-duration`).

# راهنمای فارسی کیت تایپوگرافی berlin × kawe

این بسته، لوگوتایپ berlin × kawe را به یک سیستم تایپوگرافی کاربردی برای سند، رابط نرم‌افزار، نمودار و پست‌های متنی شبکه‌های اجتماعی تبدیل می‌کند.

## ساختار اصلی

- Display Heavy برای لوگوتایپ، عنوان‌های اصلی و جمله‌های کوتاه و قدرتمند است.
- Text Regular برای متن‌های توضیحی، کپشن، سند و رابط کاربری استفاده می‌شود.
- Mono Data مخصوص نام فایل، تاریخ، موقعیت، متادیتا و برچسب نمودارهاست.
- برای فارسی، Vazirmatn Variable پیشنهاد اصلی و Peyda گزینه حرفه‌ای لایسنس‌دار است.

## قواعد کلیدی

1. نام برند همیشه به صورت `berlin × kawe` نوشته شود.
2. از علامت واقعی `×` استفاده شود، نه حرف x.
3. لوگوتایپ اصلی lowercase و در یک خط است.
4. فاصله حروف عنوان‌ها فشرده و کنترل‌شده باشد.
5. قاب بخشی از ترکیب‌بندی است. کراپ فقط وقتی مجاز است که خوانایی کامل بماند.
6. فونت Mono برای داده و متادیتاست، نه تیتر اصلی.
7. در فید سوشال، پست‌های متراکم و خلوت به صورت متناوب استفاده شوند.

نسخه‌های Editable SVG برای ویرایش‌اند. نسخه‌های Outlined SVG ظاهر را روی هر سیستم حفظ می‌کنند. فایل‌های PNG برای انتشار آماده‌اند.

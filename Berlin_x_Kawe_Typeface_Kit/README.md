# Berlin x Kawe Typeface Design Kit

This kit turns the berlin × kawe wordmark into a working typography system for documents, interfaces, charts and text-only social media.

## Core system

- Display Heavy: Nimbus Sans Bold in the editable templates, with tight tracking and optional 1-2 px optical thickening. For final professional production, Neue Haas Grotesk Display Black or Helvetica Now Display Black is recommended.
- Text Regular: Nimbus Sans Regular for editorial text, captions and interface copy.
- Mono Data: Nimbus Mono PS for filenames, locations, dates, axes and system labels.
- Persian: Vazirmatn Variable is the preferred open-source family. Peyda is a suitable licensed alternative.

## Master rules

1. Write the name exactly as `berlin × kawe`.
2. Use the true multiplication sign `×`, never the letter `x`.
3. Keep the master lockup lowercase and on one line.
4. Use tight display tracking between -4% and -8%.
5. Treat the canvas edge as part of the composition. Crop at no more than two edges and preserve recognition.
6. Use Mono for metadata, not for headlines.
7. Alternate quiet and dense social posts to create feed rhythm.

## Folders

- 01_Guide: complete visual manual and source pages.
- 02_Lockup: editable, outlined and PNG wordmarks.
- 03_Social: square, portrait and story templates.
- 04_Software: archive dashboard and file-index environments.
- 05_Documents: A4 cover and editorial page templates.
- 06_Charts_and_Diagrams: bar, line and hierarchy templates.
- 07_Tokens: JSON and CSS implementation values.
- 08_Reference: selected and updated raster references.

Editable SVGs require the named fonts. Outlined SVGs preserve appearance on any system. PNG files are publishing-ready previews.
